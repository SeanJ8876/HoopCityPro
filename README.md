HoopCityPro 

The Future of Hooping Is Here. Don't Just Play. Be Seen.

HoopCityPro is a web app built to help local rec leagues manage schedules, scores, and standings without messy spreadsheets. It gives community basketball leagues the same quality tools the pros get — clear standings, easy scheduling, and stats that celebrate every player's hustle.

About the Project

HoopCityPro started as a weekend project to solve a real problem for local rec leagues. Today it powers schedules and stats for community leagues across the city, giving players and organizers a clean, centralized place to track everything happening on the court.

This project was built as a final project for TripleTen's software engineering program.

Features
League Standings — live-updating standings with win/loss records, win percentage, and current streaks
Game Search — search and browse games and results
User Accounts — sign up / log in to save favorite games and teams
Responsive Design — styled for both desktop and mobile
Third-Party API Integration — pulls live basketball data via a custom API service layer


Tech Stack
React — component-based UI
Vite — fast dev server and build tooling
CSS — custom styles (BEM-style class naming)
Third-Party API — live game and league data
